# 什么是鹅口疮？

> 更新时间：2026-09-16 (UTC+8)

鹅口疮

鹅口疮又名雪口病、白念菌病（Oral Thrush )，是儿童的常见病，是由白色念珠菌感染引起的口腔黏膜真菌感染,  又称口腔念珠菌病。好发于颊、舌、软腭及口唇部的黏膜，为白色斑块酷似鹅口，故称“鹅口疮”。

鹅口疮高发于2岁以内的婴幼儿及老年人。白色念珠菌寄生在健康人皮肤表面、肠道，正常情况下不致病。当营养不良或身体衰弱，长期用抗菌素和类固醇喷雾，机体抵抗力低下时致病。鹅口疮还常见于免疫缺陷，免疫功能失调的患者。

临床表现

口腔黏膜（颊、舌、牙龈、软腭及唇内部）出现白色斑块，用棉签或者压舌板不易擦掉。若用力擦去斑膜，下面黏膜潮红。应与奶块相鉴别，用棉签轻拭，奶块可移除，而鹅口疮白色斑块不易擦去。多无痛感，严重时可有不适、偶可表现拒乳。先天性或获得性免疫缺陷的患儿，病变可蔓延至咽部、食管、肠道、气管、肺，偶可侵入血液导致败血症等并发症。但健康儿童弥漫性感染十分罕见。

预防、家庭护理

1.怀孕期间阴道霉菌感染应尽早治疗。分娩新生儿接触母亲产道分泌物而感染。

2.保持良好的口腔卫生，每天刷牙两次，常更换牙刷, 不要共享牙刷。

3.婴幼儿的被褥和玩具要定期拆洗、晾晒；洗漱用具和家长分开，并定期消毒。

4.乳具(奶瓶、奶嘴、奶头、吸奶器) 餐具每次用完清洁煮沸消毒。

5.母乳喂养，喂乳前后洗手, 用温水洗乳头乳晕；婴幼儿常洗澡、勤换衣、剪指甲、勤洗手、洗玩具。

6.在幼儿园过集体生活的幼儿，用具不可混用。

7.避免摄入过酸、过咸及刺激性食物以引起疼痛。避免吃含糖和酵母的食物。

8.长期服用抗生素，激素及免疫抑制治疗，先天性或获得性免疫缺陷等。

9.使用类固醇喷雾剂，喷雾后用水冲洗口腔或刷牙。

10.保持良好的血糖控制。
